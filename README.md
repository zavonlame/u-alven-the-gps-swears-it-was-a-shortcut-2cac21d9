One line, in the GPS's own voice: its excuse for sending the driver down the
wrong road. Smug, defensive, blaming the map — with a cul-de-sac instead of
the usual recalculating joke.

## Entry

> The map swore this cul-de-sac was a shortcut, and I believed it — believing the map is literally my job, and frankly, I do it beautifully.

## Run

```sh
MAKEFUN_OUTPUT_DIR=<dir> node main.ts   # writes <dir>/entry.txt
```

`main.ts` is self-contained (Node 22 stdlib only): the entry is embedded as a
literal and checked against the gate (1–200 characters, one line, non-blank)
before it is written.
